📚 Sistem Perpustakaan

Aplikasi web perpustakaan untuk mengelola buku, pengguna, dan proses peminjaman secara sederhana.

✨ Fitur

- 📖 Katalog buku
- 🔐 Login & Register
- 👤 Manajemen pengguna
- 📚 CRUD buku
- 📋 Peminjaman buku
- 🔄 Pengembalian buku
- 🛠️ Dashboard Admin
- 👤 Profile pengguna

🛠️ Tech Stack

- Laravel 12
- PHP
- Blade
- Tailwind CSS
- Vite
- MySQL / SQLite

🚀 Instalasi

git clone <repository-url>
cd perpuspweb

composer install
npm install

cp .env.example .env
php artisan key:generate

php artisan migrate

npm run dev

Jalankan aplikasi:

php artisan serve

Buka:

http://127.0.0.1:8000
